## 更新內容
### 鎖屏歌詞（正式功能）
- 「設定 › 懸浮視窗與手勢 › 鎖屏歌詞」，預設關閉。開啟後，播放有同步歌詞的歌時，會有一則 FlowLyrics 通知：標題是目前這句、下面是下一句，只在換句時更新，不響鈴、不振動。
- 實測（Galaxy S24+／One UI 9.0）：這則通知出現在原生鎖屏時鐘正下方，原生時鐘、桌布與 One UI 媒體膠囊都保持原樣。
- 懸浮歌詞與音波的常駐通知不再顯示在鎖屏上，歌詞通知不會再和它們疊成「2」。
- 在鎖定畫面點這則通知，仍會開啟 FlowLyrics 的播放頁（大封面、幾句歌詞、小貓進度條與播放鍵），不會解除鎖定。
- 限制：點開系統媒體膠囊（全畫面媒體檢視）時，系統會隱藏所有通知，這時看不到歌詞；通知外觀與位置由系統決定。

### 「即時更新」顯示（測試）
- 鎖屏歌詞開啟後，可再開「以『即時更新』顯示（測試）」。這是 Android 16 起的通知形式，可能會釘在鎖屏或三星 Now Bar；實際出現在哪裡、會不會出現，由系統決定，需要實測。
- 設定頁會顯示系統是否允許 FlowLyrics 發送即時更新，以及最近一次是否符合條件。Android 15 以下不支援，開了也不會有變化。

### 移除
- 鎖屏疊字相容性測試：實測確認系統鎖屏會隱藏一般 App 的懸浮視窗，已移除（殘留的測試紀錄也會刪除）。

使用與前版相同的固定金鑰簽署，版本碼 1058。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 權限、更新及支援 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。既有歌詞、偏移、套用的對應與設定都會保留。

附件提供 APK 與同名 SHA-256 校驗檔。
