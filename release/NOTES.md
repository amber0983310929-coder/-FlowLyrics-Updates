## 更新內容
### 新增「全域歌詞同步」
- 位置：設定 →「車機、播放器與同步」→「同步」→「全域歌詞同步」。一次把所有歌曲的歌詞提前或延後（每次 0.1／0.5 秒，最多 ±10 秒），可一鍵重設。
- **不會動到的歌曲**：
  - 已經單獨手動調整過同步的歌曲（手動調成 0 也算，會維持 0）。
  - 手動上傳／編輯的本機歌詞（仍可單獨調整；若該首改用線上版本，沒單獨調整過時會回到全域同步）。
- 其他歌曲：改了全域同步後，正在播放的那首立刻套用。
- 主畫面「同步」面板會說明目前是套用全域同步、單獨調整，或本機歌詞不套用。按「改回全域同步」（懸浮歌詞上點偏移數字）可清除這首的單獨調整。
- 藍牙輸出補償維持原本做法，另外再加上去。
- 全域同步會一併納入備份與還原。

**注意**：舊版把某首歌「重設為 0」時會直接刪除紀錄，所以那些歌現在會被視為沒調整過，會套用全域同步。

使用與前版相同的固定金鑰簽署，版本碼 1106。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 權限、更新及支援 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。既有歌詞、偏移、套用的對應與設定都會保留。

附件提供 APK 與同名 SHA-256 校驗檔。
本版尚未在手機上實測。
