## 更新內容
### 私人歌詞庫：一般使用者免登入讀取
- App 內建歌詞庫的唯讀代理，一般使用者**不需登入、不需任何設定**，播放時就會自動先查私人歌詞庫，再查公開歌詞庫。
- 歌詞庫合併新歌詞後，約 1～5 分鐘內、下一次播放該歌曲就會用到新內容。
- 維護者仍以 GitHub 登入上傳歌詞（以 Pull Request 送出，合併即生效）。
- 目前私人歌詞庫還沒有任何歌詞，所以暫時不會看到差異；歌詞加入後就會自動生效。

使用與前版相同的固定金鑰簽署，版本碼 1029。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。安裝仍須在 Android 系統畫面確認。

附件提供 APK 與同名 SHA-256 校驗檔。
本版尚未完成手機與車機的實機驗收；唯讀代理已實際連線測試（目前歌詞庫為空），但尚未以含歌詞的歌詞庫在手機上實測。
