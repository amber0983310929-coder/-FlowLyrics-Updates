## 更新內容
### 新場景：楓葉夜橋
- 設定 → 外觀 →「場景背景（試用）」可選「楓葉夜橋」：月夜、小橋、流水與楓樹。
- 楓葉飄落、前景楓枝輕輕晃動；開啟「播放音波」時，高音會亮起星光，低音在石板路上泛起光漣漪。
- 小貓在石板路上慵懶走動。

### 場景的歌詞區封面
- 專輯封面完整顯示（不再被裁掉），依整個右側的高度放大置中。
- 調得更淡，背景和封面都看得到，只有最外圈淡出。

### 車機模式左欄
- 改成純旋轉唱片（不再有底座與唱臂），專輯封面佔唱片直徑的 2/3。
- 播放時旋轉、暫停時慢慢停下；可在設定 → 車機 →「車機左欄的封面」切換。

使用與前版相同的固定金鑰簽署，版本碼 1141。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 權限、更新及支援 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。既有歌詞、偏移、套用的對應與設定都會保留。

附件提供 APK 與同名 SHA-256 校驗檔。
本版尚未在手機上實測。
