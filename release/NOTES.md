## 原生鎖屏疊字相容性測試版
這一版用來在你的手機上實測：FlowLyrics 能不能在**保留三星原生鎖屏**（時鐘、日期、桌布、Spotify 原生膠囊與展開畫面）的情況下，在時鐘下方疊上少量歌詞。**相容性尚未確認**；功能預設關閉，要自己在設定中開始測試。

### 怎麼測
覆蓋安裝本版 → 「設定 › 懸浮視窗與手勢 › 鎖屏疊字相容性測試」按「開始測試」→ 確認桌面上方看得到「FlowLyrics 鎖屏疊字測試」與每秒更新的計數 → 用 Spotify 播歌 → 熄屏再亮屏（不解鎖）→ 點原生 Spotify 膠囊展開 → 在設定中標記「是／否」（看不看得到、原生時鐘是否保留、按鍵能否操作）並填寫 One UI 版本 → 按「匯出測試報告」傳回。

- 測試文字是一小塊透明、不能點的文字，不會攔截原生畫面的操作；按「停止測試」會完全移除。
- 報告記錄裝置、系統版本、鎖定狀態、視窗是否建立成功與時間點；**視窗建立成功不代表看得到**，看不看得到要由你標記。報告只在你按匯出時才分享，不會自動上傳，也不含帳號或通知內容。
- 開發端查證：Android 開源程式碼（AOSP）的規則是，系統鎖屏顯示時會隱藏這類一般 App 懸浮視窗；三星是否不同，需要這次實測確認。

### 其他
- 「鎖屏播放頁」備案保留不變。
- 小貓、懸浮窗、車機等其他功能與 0.4.21 相同。

使用與前版相同的固定金鑰簽署，版本碼 1055，來源 commit 419bda9。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 權限、更新及支援 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。既有歌詞、偏移、套用的對應與設定都會保留。

附件提供 APK 與同名 SHA-256 校驗檔。
