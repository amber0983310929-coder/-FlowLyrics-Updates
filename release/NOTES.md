## 更新內容
### 手寫紙條換上手寫字型
- 「手寫紙條」歌詞島的歌詞改用開放授權的繁體中文手寫字型「芫荽 Iansui」（SIL Open Font License 1.1，© The Iansui Project Authors），字形依台灣教育部標準字體設計。
- 少數字型裡沒有的字，會自動改用系統字體顯示，不會出現方框。
- 因為附帶了字型，安裝檔大小增加約 4MB。

使用與前版相同的固定金鑰簽署，版本碼 1067。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 權限、更新及支援 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。既有歌詞、偏移、套用的對應與設定都會保留。

附件提供 APK 與同名 SHA-256 校驗檔。
