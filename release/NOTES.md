## 更新內容
### 移除「即時更新」測試選項
- 實測（Galaxy S24+／One UI 9.0）：系統回報允許即時更新、FlowLyrics 的通知也符合條件，但狀態列與通知欄沒有任何不同的呈現，因此移除這個測試選項，讓設定更簡潔。

### 不變的部分
- 鎖屏歌詞：「設定 › 懸浮視窗與手勢 › 鎖屏歌詞」，開啟後在原生鎖屏時鐘正下方顯示目前這句與下一句；歌詞通知單獨顯示，懸浮歌詞與音波的常駐通知不顯示在鎖屏。
- 在鎖定畫面點歌詞通知，開啟 FlowLyrics 的播放頁。
- 點開系統媒體膠囊（全畫面媒體檢視）時，系統會隱藏所有通知，這時看不到歌詞。

使用與前版相同的固定金鑰簽署，版本碼 1059。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 權限、更新及支援 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。既有歌詞、偏移、套用的對應與設定都會保留。

附件提供 APK 與同名 SHA-256 校驗檔。
