## 更新內容
### 私人歌詞庫：更新更快生效、錯誤分開處理
- 歌詞庫有任何新增、修改或刪除，最晚約 5 分鐘後、下一次播放該歌曲就會用到新內容；「重新搜尋」可立即更新。
- 登入、登出、更換儲存庫或分支後，已快取的歌曲會自動重新查詢。
- 讀取失敗（設定錯誤、沒有權限、離線、限流）不再被記成「沒有這首歌」，只用公開歌詞庫的結果並在 10 分鐘後重試；原因顯示在「設定 › 私人歌詞庫」。

### 私人歌詞庫：一般使用者免登入讀取（準備中）
- 新增唯讀代理模式：維護者部署代理後，一般使用者不需登入就能讀取私人歌詞庫。
- 本版尚未內建代理網址，所以一般使用者目前仍讀不到私人歌詞庫；代理部署完成後的版本才會生效。

### 點擊同步
- 藍牙補償只在當下確實使用藍牙輸出時套用，換喇叭或耳機都對得上，不會重複補償。
- 反應補償可選 0、0.15、0.3 秒，畫面上會顯示目前設定。
- 打軸途中切到背景、旋轉螢幕或被系統回收，回來後可以接續；未儲存就離開時會詢問保留或放棄。
- 開始前可以先預覽整理結果（會移除哪些行）；打軸按鈕固定在畫面底部，大小隨螢幕調整。

使用與前版相同的固定金鑰簽署，版本碼 1028。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。安裝仍須在 Android 系統畫面確認。

附件提供 APK 與同名 SHA-256 校驗檔。
本版尚未完成手機與車機的實機驗收；私人歌詞庫的 GitHub 登入、上傳與唯讀代理尚未以真實 GitHub 儲存庫及 Cloudflare 實測。
