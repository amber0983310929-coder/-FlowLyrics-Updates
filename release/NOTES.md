## 更新內容
### 貼上歌詞並點擊同步
- 歌詞選單新增「貼上歌詞並點擊同步」：貼上整首歌詞（會自動去掉時間戳、作詞作曲等資訊與空行），從頭播放歌曲，每一句開始唱時點一下大按鈕。
- 按錯可以「退一句」或「重來」；全部點完後存成這首歌的動態歌詞，下次播放直接顯示，也會取代錯誤的版本。
- 時間軸完全來自你的點擊，不分析音訊、不估算；點完後仍可用 ±0.1 秒微調。

### 私人歌詞庫改用 GitHub
- 私人歌詞庫改為你自己的 GitHub 私人儲存庫，以 GitHub 帳號登入（在 GitHub 輸入 App 顯示的代碼）。
- 播放時先查私人歌詞庫，再查公開歌詞庫，你們確認過的版本優先。
- 點擊同步完成後或在編輯器中，可以把歌詞上傳到私人歌詞庫（以 Pull Request 送出，儲存庫擁有者合併後其他成員就找得到）。
- 需要先在 GitHub 建立私人儲存庫與 GitHub App，步驟見 App「設定 › 私人歌詞庫」的說明。

使用與前版相同的固定金鑰簽署，版本碼 1026。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。安裝仍須在 Android 系統畫面確認。

附件提供 APK 與同名 SHA-256 校驗檔。
本版尚未完成手機與車機的實機驗收；私人歌詞庫的 GitHub 登入與上傳尚未以真實 GitHub 儲存庫實測。
