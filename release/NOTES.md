## 更新內容
### 歌詞小貓：點頭與重拍摔倒
- 跟著鼓點點頭：身體往前輕輕一沉（取代原本的原地輕跳）。
- 特別重的拍子：嚇一跳往上彈 → 從歌詞上摔下去、空中往後翻 → 側躺約 0.7 秒 → 爬起來 → 跳回目前這句的末端。
- 摔倒至少間隔 15～25 秒（隨機），不會每個重拍都摔；剛出現的幾秒內也不會摔。
- 開啟「降低動畫」時不點頭、不摔倒。

### 修正：小貓不再站到上一句或壓到字
- 句子最後一行太長、放不下小貓時，那一行會提早換行，在行尾留出小貓的位置；小貓一律坐在句子最後一個字旁邊。

使用與前版相同的固定金鑰簽署，版本碼 1096。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 權限、更新及支援 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。既有歌詞、偏移、套用的對應與設定都會保留。

附件提供 APK 與同名 SHA-256 校驗檔。
本版尚未在手機與車機上實測；點頭與摔倒跟真實音樂的搭配需要實際播放確認。
