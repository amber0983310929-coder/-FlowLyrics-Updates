## 更新內容
### 懸浮歌詞放大後貼邊不留空白
- 放大的視窗靠邊放開時，幾乎貼邊的那一側會自動延伸到螢幕邊緣，不再留一小條空白。
- 拖曳角落或邊調整大小時，只延伸你拉的那一側，視窗不會被移動；刻意留下的位置不受影響。

### 按鈕彈起回饋
- 歌詞、同步、懸浮、設定等按鈕按下時縮小、放開時彈起；「降低動畫」開啟時不動。
- 主畫面這四個按鈕改為圖示在上、文字在下，歌名與播放鍵不會被擠掉。

### 全新的同步調整面板
- 顯示「現在這一句」，邊聽邊調。
- 大字顯示目前調整量，可拖曳刻度（左延後、右提前，每格 0.1 秒，有震動回饋）。
- 按鈕依情況分組：「歌詞太早出現」按延後、「歌詞太晚出現」按提前。
- 有藍牙補償時一併提示；可一鍵重設。面板在下方，不會遮暗歌詞。

### 其他
- 歌詞面板加上圖示。
- 編輯器把清除時間、匯入、匯出收進「更多」，上傳到私人歌詞庫只顯示給已登入的維護者。

使用與前版相同的固定金鑰簽署，版本碼 1040。

## 安裝說明
已安裝 v0.4.1 以後版本的使用者可在 App「設定 → 權限、更新及支援 → 檢查更新」取得本版，或直接覆蓋安裝，無須解除安裝。既有歌詞、偏移、套用的對應與設定都會保留。

附件提供 APK 與同名 SHA-256 校驗檔。
本版尚未在手機或車機上實測；已用與使用者手機相同的 1080×2340 尺寸在模擬環境截圖確認。
